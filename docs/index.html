AISBench-Prefix-Tools

Windows 桌面工具 —— 远程部署 AISBench 测试环境，自动设计 / 执行 prefix cache 性能测试，自动提取结果生成 CSV，并内置结果对比分析。

⬇ 下载最新版 EXE GitHub 仓库
免安装 Python 与任何依赖 · 双击即用 · Windows 10/11

工具简介

AISBench-Prefix-Tools 是面向 Windows 用户的 prefix cache 性能测试工具。它通过 SSH 管理远程 Linux 执行机，自动完成已有镜像复用或镜像上传加载、容器创建、配置生成、测试脚本设计、测试执行、日志下载与 CSV 提取，并提供独立的结果对比分析能力。

🚀

五步向导

从 SSH 连接到生成结果 CSV，一条流程完成远程环境部署与测试执行。

🧮

用例自动设计

根据 KV cache 容量、DP 组数、输入输出长度自动计算请求数与并发数。

🧾

远程日志工具

选择服务器、容器和日志文件，一键筛选 KV cache 关键信息并回填测试参数。

📊

结果对比分析

选择两个结果 CSV，按输入规模匹配用例，输出差异表格、分组柱状图与可标注的 CSV/PNG 导出。

整体流程

连接执行机→ 选择镜像与模型并部署→ 写入 config.py→ 设计用例→ 执行测试→ 生成 CSV→ 对比分析

快速开始

方式一：直接下载 EXE

下载最新稳定版或 Nightly 构建后，双击即可运行，无需安装 Python 和任何依赖。

稳定版：https://github.com/ucm-system/AISBench-Prefix-Tools/releases/latest/download/AISBench-Prefix-Tools.exe
Nightly：https://github.com/ucm-system/AISBench-Prefix-Tools/releases/download/nightly/AISBench-Prefix-Tools.exe

开发分支构建：推送 dev 分支后 CI 自动打包，在 Actions 对应运行页底部 Artifacts 区域下载（保留 90 天，不产生 Release）。入口：dev 分支构建列表。

方式二：从源码运行

git clone https://github.com/ucm-system/AISBench-Prefix-Tools.git
cd AISBench-Prefix-Tools
pip install -r requirements.txt
python main.py

方式三：本地打包 EXE

pip install -r requirements.txt
build_exe.bat
开始前请准备 远程 Linux 执行机的 SSH 地址、端口、账号和密码或密钥；执行机上已有的 AISBench Docker 镜像，或需要上传的镜像 tar 包；可访问的模型权重目录；已启动的 vLLM 推理服务。
镜像下载 当前推荐镜像：AISBench v3.1-20261013-master。若执行机没有可用镜像，可在步骤 2 的上传模式点击“镜像下载链接”，或直接访问 GitHub Releases 下载。

界面语言切换

中文 / English

左侧边栏底部提供 语言 / Language 下拉框，可在中文和 English 之间切换；切换后界面立即重建，无需重启程序，选择会保存到本机用户配置。

界面控件、弹窗提示（如“下一步”校验、部署与清理确认、结果摘要）以及状态栏动态消息均随所选语言显示；弹窗按钮（确定/取消/是/否）也由程序自绘并跟随所选语言，不受操作系统语言影响。

切换语言只改变界面呈现：当前步骤、SSH 登录信息、镜像/模型/配置输入与执行结果都会完整保留，不会跳回第一步。

步骤 1：SSH 连接执行机

STEP 1 / 5

填写执行机 IP、SSH 端口、用户名以及密码或密钥，点击“测试连接”。状态栏确认连接成功后，左侧步骤 2 才会进入可用状态。

连接后自动体检 连接成功后工具会自动扫描本工具创建的容器；如发现上次退出未清理的 aisbench-test-* 容器，会提示打开清理窗口勾选删除。
字段说明示例
执行机 IP远程 Linux 服务器地址141.xx.xx.xx
SSH 端口默认 22，按实际安全组配置填写22
用户名远程服务器登录用户root
密码 / 密钥二选一；密钥支持 RSA 或 Ed25519server.pem
提示 如果连接超时，请检查防火墙和安全组是否放行 SSH 端口，并确认密钥文件格式可用。

步骤 2：Docker 部署与模型配置

STEP 2 / 5

点击“查看已有镜像”读取执行机 Docker 镜像列表并优先复用 AISBench 镜像；未发现可用镜像时自动切换为上传 tar 包。模型、vLLM 服务、代码来源、临时部署目录、残留容器清理与部署日志都在同一页面完成。

字段说明
AISBench 镜像来源点击“查看已有镜像”读取执行机镜像列表并选择；未发现镜像时自动切换到上传模式。
镜像 tar 包上传模式专用，选择本地 AISBench Docker 镜像文件；可点击“镜像下载链接”直达 Releases。
临时部署目录默认 /tmp/AISBench_Prefix_Tools；仅部署期间暂存镜像 tar 和代码，导入容器后自动删除。
清理残留容器列出并勾选删除上次未清理的 aisbench-test-* 容器，可同时清理旧版遗留的临时目录。
测试代码来源默认使用程序内置代码，也可选择本地 zip 包。
模型路径远程执行机上的模型权重目录，可点击“浏览远程目录”定位。
模型名称对应 vLLM 的 --served-model-name 参数。
vLLM 服务 IP / 端口推理服务访问地址，端口通常为 8000。
API Key服务鉴权令牌；未开启鉴权时留空。

自动执行流程

检查 Docker→ 复用已有镜像或上传加载→ 暂存测试代码→ 创建容器(仅挂载模型)→ docker cp 导入代码→ 删除宿主机临时目录
  • 已有镜像模式会先校验镜像仍存在，然后跳过上传与 docker load。
  • 上传模式会优先读取 tar 包 manifest.json；镜像已存在时同样跳过重复加载。
  • 容器自动命名 aisbench-test-MMDDHHMM，并附加管理 label org.aisbench-prefix-tools.managed=true。
  • 模型路径按原路径挂载；测试代码不挂载，而是在容器创建后通过 docker cp 导入 /benchmark/ais_bench/aisbench_auto_tools_prefix-main。
  • 代码导入成功后立即删除宿主机临时目录，宿主机不再保留代码、config.py 或日志。
  • config.py 与测试脚本直接写入容器内部（内容经 base64 编码，避免引号转义问题）。
  • 部署失败时临时目录会保留用于排障，修复后重新部署即可。
重复执行 同名旧容器会自动删除并重建；也可以先手动清理容器后再点击部署。

步骤 3：配置 config.py

STEP 3 / 5

模型与服务字段会从步骤 2 自动带入。确认或修改配置后点击“保存配置到容器”，配置会直接写入容器内部工作区；再用“验证配置”回读容器内文件并与界面值逐项比对。

字段默认值 / 示例说明
MODEL_NAMEds步骤 2 中填写的模型名称。
MODEL_PATH模型目录模型权重在远程机上的路径。
HOST_IP / HOST_PORT8000vLLM 服务地址。
DATASET_PATH自动填充测试代码在容器内部的工作区路径。
DEFAULT_PERFORMANCE_TESTdefault_perf稳态测试填写 stable_stage。
OUTPUT_DIR./outputs/default容器内日志输出目录。
POD_INFO[]多 DP 场景必填，格式如 ip:port,ip:port。

步骤 4：设计测试用例

STEP 4 / 5

填写单个 DP 组 KV cache、DP 组数、模型最大上下文与前缀命中率，选择输入和输出长度后点击“生成测试用例”。表格会给出推荐请求数、最小请求数、并发数和 KV 使用率。

字段说明示例
单个 DP 组 KV cache从 vLLM 日志解析或手动填写198469
DP 组数data-parallel-size4
最大请求长度单条请求最大 token 数131072
前缀命中率repeat_rate，范围 0~10.9
请求发送速率0 表示 Burst；大于 0 表示固定速率0

自动计算规则

最小请求数 = floor(total_kv_cache / input_len / repeat_rate) + 1
推荐请求数 = 最小请求数 × 2
并发数 = floor(total_kv_cache / (input_len + output_len))
  • 生成前会自动跳过超出模型最大上下文长度的选项。
  • 表格支持双击编辑 Input、Output、请求数和并发数。
  • 支持添加、复制和删除用例。
  • 请求数低于最小值时仅提醒，不会强制拦截。
手动查询命令 界面会给出可复制的 grep 命令；也可以点击“从日志自动获取”打开远程日志工具自动解析。

步骤 5：执行测试并生成 CSV

STEP 5 / 5

确认本地结果保存目录后，点击“执行测试 → 生成CSV”。工具会将测试脚本写入容器内部、先检查模型路径、逐用例执行、从容器下载日志并在本地解析 CSV。

预检查模型路径→ 生成 .sh→ 写入容器→ 容器内执行→ docker cp 下载日志→ 解析 CSV

输出位置

默认目录：C:/Users/<用户名>/aisbench_results
日志目录：test_logs_<时间戳>/test_<序号>_<input>_<output>.log
结果文件：results_test_logs_<时间戳>.csv

结果摘要字段

摘要表格包含 Input、Output、请求数、最大并发、并发、输入吞吐、输出吞吐、TTFT、TPOT、QPS、HBM 命中率和外部缓存命中率，并标注 CSV 与日志路径。

测试命令示例 每次执行会随机生成 seed，保证数据集可复现且不同轮次不同；当请求发送速率大于 0 时，还会追加 request_rate 参数。

远程日志工具

在步骤 4 点击“从日志自动获取”或“查看日志”，即可打开远程日志工具。它支持选择服务器、日志来源和具体日志文件，并直接给出筛选结果。

支持的日志来源

来源说明
宿主机文件通过远程目录树选择服务器上的日志文件。
容器内文件自动列出运行中容器，进入容器后选择日志文件。
容器 stdout直接读取 docker logs 输出。

筛选 KV cache

  1. 选择服务器。默认使用当前执行机，也可以临时连接其他服务器。
  2. 选择宿主机文件、容器内文件或容器 stdout。
  3. 选择目标日志并点击筛选。
  4. 解析“单个 DP 组 KV cache”和“模型最大上下文”后，点击“一键填入”。
免手敲命令 界面会自动生成实际执行的 grep 命令；用户也可以直接复制该命令到终端执行。

查看指定日志文件

选择日志后点击“查看日志”，会在独立窗口展示内容。宿主机与容器内文件取尾部 2MB，容器 stdout 取尾部 5000 行，支持横向滚动和一键复制。

结果对比分析

结果对比分析是独立入口，不需要连接执行服务器。可以从左侧边栏打开，也可以在步骤 5 的结果摘要右侧打开。

使用步骤

  1. 分别选择 CSV A 和 CSV B，两者必须为本工具生成的结果 CSV。
  2. 需要业务名称时，修改“标注 A / 标注 B”；默认取文件名，手工标注不会被重新选择文件覆盖。
  3. 工具校验表头格式，缺少或多余字段会明确提示。
  4. 在匹配列表中勾选要对比的用例。
  5. 按分组选择需要观察的指标。
  6. 点击“开始对比”，查看差异表格和柱状图。
  7. 需要留存时，点击“导出对比 CSV”保存差异表格，或点击“导出对比图”把每个指标的柱状图导出为 PNG。

匹配规则

  • 优先按输入长度和输出长度精确匹配。
  • 剩余用例回退为仅按输入长度匹配，并在界面标注匹配方式。
  • 匹配列表同时展示两侧请求数和 Max_CC，便于确认测试条件。

结果内容

区域说明
差异表格展示 Req A/B、Max_CC A/B，以及每个指标的 A 值、B 值、Δ 和 Δ%。
柱状图每个指标自动绘制分组柱状图；图例使用自定义 A/B 标注，横坐标展示输入、输出、请求数和 Max_CC。
导出 CSV将当前差异表格保存为新的 CSV 文件，默认文件名包含 A/B 标注。
导出图片把每个已勾选指标的柱状图导出为 1280×640 PNG，文件名包含 A/B 标注与指标名。
注意 对比结果中的 Δ = B − A。请优先选择输入规模和并发条件一致的用例，否则差异可能同时来自系统变化和测试条件变化。

环境清理与退出

测试完成后会自动询问是否清理远程环境。也可以随时点击“清理环境”手动执行；上次退出未清理的容器可在步骤 2 通过“清理残留容器”删除。

操作结果
清理远程环境停止并删除容器，删除残留暂存文件；本地结果不受影响。
清理残留容器步骤 2 提供勾选列表，可跨会话删除 aisbench-test-* 容器和旧版遗留的临时目录。
保留环境容器保留，便于继续排查或复用；下次连接时会再次提醒。
退出程序点击“完成”或窗口关闭按钮；若容器仍在运行，会再次提醒。
安全边界 残留容器清理只识别本工具创建的容器（aisbench-test- 前缀或管理 label），不会影响执行机上的其他容器。

常见问题

执行机已有镜像，还需要上传 tar 包吗？

不需要。在步骤 2 点击“查看已有镜像”并选择镜像，部署时会校验该镜像仍存在，然后跳过上传与 docker load。未发现可用镜像时才切换到上传模式。

上传镜像后无法自动识别镜像名？

工具优先读取 tar 包内 manifest.json 获取镜像名；读取失败时再解析 docker load 输出。可在步骤 2 部署日志中查看结果。

如何切换中文 / English 界面？

在左侧边栏底部选择 语言 / Language；界面会立即重建，选择会保存到本机用户配置，下次启动自动恢复。弹窗提示与状态栏动态消息也会同步切换。

模型路径浏览看不到文件？

远程目录浏览器默认从根目录开始，双击 DIR 进入子目录。部分目录可能因权限问题无法列出。

POD_INFO 应该怎么填？

单 DP 场景留空即可。多 DP 场景填写每个节点地址并用逗号分隔，例如 141.1.1.11:8000,141.1.1.12:8000。

如何重新部署？

再次点击“开始部署”会删除同名旧容器并重新创建，也可以先手动删除容器后重试。

上次退出没有清理，怎么删除遗留容器？

重新连接后工具会自动扫描并提醒；也可以在步骤 2 点击“清理残留容器”，勾选要删除的容器，可同时清理旧版遗留的临时目录。

远程的 /tmp/AISBench_Prefix_Tools 目录为什么部署后不见了？

该目录现在只是部署暂存区，代码通过 docker cp 导入容器后会自动删除；后续 config.py、脚本和日志都在容器内部。

结果 CSV 可以单独解析吗？

可以。对比分析工具只要求 CSV 表头与本工具生成格式一致；日志解析脚本也可独立调用。
